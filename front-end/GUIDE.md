# Guia local - Front-end

Este guia cobre somente implementacao local do front-end.

## Fluxo local

1. Receber task da raiz (`../tasks/*.md`)
2. Confirmar que `Tipo` inclui `front` ou `shared`
3. Implementar apenas o escopo front-end
4. Rodar validacoes locais
5. Reportar resultados para consolidacao da task na raiz

## Nao e responsabilidade local

- gerar backlog global
- definir ordem global de tarefas
- atualizar contrato sem task especifica

## Comandos principais

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run test`
